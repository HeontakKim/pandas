# gemcraft — 아크 그리드 젬 가공 행동 계산기

로스트아크 아크 그리드의 젬 가공에서 매 차수 표시되는 **서로 다른 가능성 4개**를
입력하면 `가공하기`, `다른 항목 보기`, `가공 완료` 중 목표 달성에 가장 유리한 행동을
계산한다.

중요: 플레이어가 네 가능성 중 하나를 고르는 시스템이 아니다. `[가공 하기]`를 누르면
표시된 네 가능성 중 하나가 각각 25% 확률로 무작위 적용된다.

## 브라우저에서 사용

`web/gemcraft.html`을 브라우저로 열면 된다. 외부 리소스와 서버가 필요 없으며 계산과
입력은 모두 로컬 브라우저 안에서 처리된다.

1. 젬 등급과 목표를 선택하고 계산을 시작한다.
2. 인게임에 표시된 서로 다른 가능성 4개를 계산기에서 선택한다.
3. 계산기가 세 행동의 가치를 비교해 추천한다.
4. 가공했다면 실제로 무작위 적용된 가능성을 입력해 다음 차수로 진행한다.

## 명령행 사용

```bash
python3 -m gemcraft.cli rank --grade 희귀 --goal "target=4,4,0,0" \
  --hand "will+1,point+2,keep,eff1+1"

python3 -m gemcraft.cli play --grade 희귀 --goal "target=4,4,0,0"
python3 -m gemcraft.cli sim --grade 희귀 --goal ancient --runs 20000
```

효과 종류까지 목표에 포함하려면 `+good`을 사용한다. 각 젬 세부 타입에는 서로 다른
효과가 4종 있으므로 `--p-good`은 그중 원하는 효과의 비율이다. 딜러용 효과 2종을
원하면 `--p-good 0.5`다.

## 계산 모델

상태는 네 옵션 레벨, 두 효과의 적합 여부, 누적 비용, 남은 가공 횟수와 다른 항목 보기
횟수로 구성된다. 유한 지평 동적 계획법으로 다음 행동의 가치를 계산한다.

```text
process(hand) = 1/4 × Σ V(가능성 적용 후 상태)
V(state)      = E_hand[max(process(hand), reroll, complete)]
```

반영한 공식 규칙:

- 한 차수의 네 가능성에는 중복이 없다.
- 가공 시 네 가능성 중 하나가 각각 25%로 무작위 적용된다.
- 한 번 이상 가공한 뒤에는 `다른 항목 보기`와 `가공 완료`를 사용할 수 있다.
- 마지막 차수에는 비용 변경과 다른 항목 보기 증가 가능성이 등장하지 않는다.
- 효과 변경 시 기존 효과와 반대편 슬롯의 효과는 후보에서 제외된다.
- 미등장 가능성의 확률 질량을 제외하고 나머지 확률을 재정규화한다.

손패는 확률 가중 비복원 추출로 모델링한다. 가능한 모든 손패를 모든 상태에서 열거하면
브라우저 계산량이 지나치게 커지므로, **손패가 보이기 전 상태 기대치와 리롤 기준값은
상태별 고정 비복원 표본 24개로 근사**한다. 같은 입력은 항상 같은 결과를 낸다.
사용자가 입력한 실제 네 가능성에 대한 가공 기대값과 세 행동의 비교는 정확하다.

현재 목표 함수는 목표 달성 확률 또는 레벨 점수를 최대화한다. 골드와 초기화권의 경제적
가치를 함께 최적화하는 기능은 아직 포함하지 않는다.

확률표와 상수는 `gemcraft/rules.py` 및 브라우저 엔진의 `RULES`에 있다. 양쪽이
달라지면 교차검증 테스트가 실패한다.

## 테스트

```bash
python3 -m venv .venv
.venv/bin/python -m pip install pytest numpy
npm install
.venv/bin/python -m pytest tests/ -q
npm test
```

테스트는 확률표, 상태 인코딩, 마지막 차수 미등장 조건, 중복 없는 손패, 조건부 효과
변경 확률, 시뮬레이션, Python/JavaScript 값 함수 일치와 실제 DOM 사용자 흐름을 검사한다.

## 구조

```text
gemcraft/             Python 계산 엔진·CLI·시뮬레이터
web/gemcraft.html     설치 없는 단일 파일 브라우저판
tests/                Python/JavaScript 교차검증 및 UI 테스트
```
